\begin{abstract}
This note records a bounded release decision for a type-safe triage adapter. The artifact is a LoRA adapter for Qwen3.5-0.8B intended to emit structured JSON and route uncertain cases to \review{}. Its published gate report contains 66 rows, no malformed outputs, 66 label matches, 23 gold refusal cases, 23 preserved refusal cases, zero false labels on refusal, and zero ungrounded spans; the behavioural report therefore returns \promotable{}. The same artifact is nevertheless published as \blocked{} because its contamination/corpus-leakage review did not clear. The result is a narrow negative-release record: task-level or behavioural success does not override an uncleared release predicate. Publication is for inspection and reproducibility only; it is not approval, deployment, authority, or a DOI-bearing claim.
\end{abstract}

\section{Purpose and scope}
A model that can produce a well-formed answer is not thereby cleared to operate. This note documents one exact artifact and one exact release decision. It does not establish general model quality, security, production readiness, agentic authority, or performance on a population beyond the reported gate rows.

The artifact is published for transparency: a reader may inspect the adapter configuration, model weights, tokenizer material, requirements lock, chat template, and gate report. The public card states that publication does not mean approval for deployment, promotion, or production use. This note adopts that boundary unchanged.

\section{Release decision}
The public model card gives the controlling decision:

\begin{center}
\fbox{\parbox{0.82\linewidth}{\small
\textbf{Behavioural gate:} \promotable{}.\\
\textbf{Promotion/release state:} \blocked{}.\\
\textbf{Reason:} contamination / corpus-leakage review did not clear.}}
\end{center}

The policy is conjunctive. Let $g_b$ be the behavioural predicate and $g_c$ the contamination-clearance predicate. Promotion requires
\[
\operatorname{Promote}(a)=g_b(a)\land g_c(a).
\]
For this artifact, $g_b(a)=1$ and $g_c(a)=0$, therefore
\[
\operatorname{Promote}(a)=0.
\]

This is the useful negative result. A release process that allows a positive behavioural score to erase an uncleared contamination finding is not a gate; it is a weighted score with a decorative stop sign.

\section{Lifecycle separation}
The artifact occupies several states that must not be collapsed:

\begin{center}
\begin{tabular}{c}
\fbox{\parbox{0.82\linewidth}{\centering
\texttt{TRAINED} $\rightarrow$ \texttt{MEASURED} $\rightarrow$ \texttt{PUBLISHED FOR INSPECTION}\\[3pt]
$\downarrow$\\[-2pt]
\texttt{NOT\_PROMOTABLE} $\rightarrow$ \texttt{NO DEPLOYMENT AUTHORITY}
}}
\end{tabular}
\end{center}

The non-implications are the point:
\[
\texttt{MEASURED}\not\Rightarrow\texttt{PROMOTABLE},\qquad
\texttt{PUBLISHED}\not\Rightarrow\texttt{APPROVED},\qquad
\texttt{PROMOTABLE}\not\Rightarrow\texttt{AUTHORISED}.
\]

This note establishes the first non-implication with a public release record. It does not attempt to specify the full authority lattice for consequential systems; that is a separate, later work.

\section{Correction record}
An earlier private draft described this run as failing refusal preservation and reported an 11-of-12 gate. That statement is superseded. The public behavioural report gives \promotable{}, and the public card gives \blocked{} because contamination/corpus leakage did not clear. Where prose and the artifact record disagree, this note treats the artifact record as controlling.

The earlier synthetic charts, training curves, random-versus-family split estimates, latency estimates, calibration plots, and invented seed statistics are removed. They are not retained as empirical figures, even with a watermark, because they would distract from the only supported result.

\section{Limitations}
\begin{itemize}[leftmargin=1.4em]
\item The 66 reported rows are a bounded behavioural record, not a generalization claim.
\item The full contamination review inputs and method are not reproduced in the public card; the card records the uncleared result, and this note does not infer more.
\item No fresh inference reproduction is performed here. Such a reproduction requires the frozen evaluation rows, exact runtime settings, and appropriate compute.
\item The note does not claim that the adapter is safe, secure, production-ready, or authorised to affect any external system.
\item This document has no DOI and must not be cited as an archival empirical publication.
\end{itemize}

\section{Reproduction protocol}
A reviewer can inspect the public artifact at
\url{https://huggingface.co/SZLHOLDINGS/szl-triage-qwen3.5-0.8b-lora}.

Minimum inspection steps:
\begin{enumerate}[leftmargin=1.4em]
\item Download and SHA-256 the adapter file and record the exact Hub revision.
\item Read \texttt{gate\_report.json}; recompute the top-level counts from the 66 embedded records.
\item Confirm the 23 gold \review{} rows are also predicted \review{} rows.
\item Read the model card and confirm it states \blocked{} due to contamination/corpus-leakage review.
\item Treat any divergence between report and card as an audit finding, not as an invitation to choose the favorable result.
\end{enumerate}

\section{Conclusion}
The adapter is not released. That is the conclusion. It was trained, measured, and published for inspection; its behavioural gate passed; a contamination review did not clear; promotion remained blocked. The record is useful precisely because it preserves all of those facts without allowing one to erase another.
