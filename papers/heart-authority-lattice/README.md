# The Heart of a Governed AI System

## Auditing a Distributed Authority Lattice Across Models, Evidence, Invariants, and Systems of Record

**Status:** working flagship-paper scaffold. No DOI. No Zenodo deposit. No claim of complete audit.

## Core claim

A governed AI system is not a model plus a policy. It is a system of separate organs:

```text
Brain proposes.
Second Brain retrieves bounded evidence.
Forge builds and measures candidates.
Models advise.
Council deliberates.
Heart admits or denies.
Ouroboros bounds recurrence.
Invariants falsify broken evidence.
Khipu/YAWAR records.
HUKLLA halts.
Egress acts only under scoped authority.
```

No formula, model, Hub artifact, receipt, score, HTTP response, or build output grants authority alone.
